🎯 MODES D'UTILISATION

MODE 1 : Hors-ligne (Recommandé) ⭐⭐⭐
   📄 Fichier : public/index-standalone.html
   ✅ Aucune installation requise
   ✅ Fonctionne directement dans le navigateur
   ✅ Photos sauvegardées localement
   ✅ Compatible tous appareils

MODE 2 : Avec serveur Python
   🐍 Commande : python server.py
   ⚠️  Requiert Python 3.6+
   📁 Photos sauvegardées sur le serveur
   🌐 Accès via http://localhost:3000

MODE 3 : Avec serveur Node.js
   ⚙️  Commande : npm install && npm start
   ⚠️  Requiert Node.js et npm
   📁 Photos sauvegardées sur le serveur
   🌐 Accès via http://localhost:3000

🎨 PERSONNALISATION

Pour modifier le titre et les couleurs :

1. Ouvrez public/index-standalone.html avec un éditeur de texte
2. Cherchez la section CSS :
   
   :root {
       --primary-color: #d4a5a5;      /* Rose/Marron principal */
       --secondary-color: #8b4c4c;    /* Rose/Marron secondaire */
   }

3. Remplacez les codes couleurs hexadécimaux

4. Pour le titre, trouvez :
   <h1>💒 Notre Mariage</h1>
   et remplacez le texte

🔧 DÉPANNAGE

PROBLÈME : "La caméra n'est pas disponible"
SOLUTIONS :
  1. Vérifiez que votre appareil a une caméra
  2. Accordez la permission d'accès à la caméra
  3. Redémarrez le navigateur
  4. Essayez avec un autre navigateur

PROBLÈME : Les photos ne s'affichent pas
SOLUTIONS :
  1. Vérifiez que le stockage local n'est pas désactivé
  2. Essayez en mode normal (pas en mode incognito)
  3. Videz le cache et rechargez

PROBLÈME : Je ne peux pas télécharger les photos
SOLUTIONS :
  1. Vérifiez que les téléchargements ne sont pas bloqués
  2. Assurez-vous d'avoir de l'espace disque
  3. Essayez un autre navigateur
